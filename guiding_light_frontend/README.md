# Guiding Light (Suga sa Dalan) - Frontend

This is the frontend for the "Suga sa Dalan" project, built with React and Vite.

## Run Locally

**Prerequisites:**
*   Node.js
*   An active instance of the `guiding_light_backend` running on a local server (e.g., XAMPP).

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the development server:
   ```bash
   npm run dev
   ```

The application will be available at `*`.
